# hsafm-eventaudit — archived observations and predictions

This directory contains two original author-controlled datasets selected for the curated `hsafm-eventaudit` source distribution, version `0.2.0rc1`. Their scientific file contents are preserved unchanged.

## Included files

- `A1-02/STAGE3B_OBSERVATION_RECORDS_V1.jsonl` — 14,958 synthetic case documents containing 957,312 nested observation records. SHA-256: `5816e0a1e5c98bc0f7931a82f740976fe7e97eb2758a7575177300f916b3fd8f`.
- `A1-04/STAGE3B_METHOD_OUTPUTS_PRETRUTH_V1.jsonl` — 119,664 archived method-prediction rows (eight per case). SHA-256: `ddd03daa50e7f6785a15cfe0b03916976d68494f4c82c0520b9ea61e210f2a71`.

The corresponding original file identities are also recorded in [`release/ORIGINAL_A1_FILE_IDENTITIES.tsv`](../release/ORIGINAL_A1_FILE_IDENTITIES.tsv).
